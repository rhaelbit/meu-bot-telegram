## 🎯 Filosofia e Regras de Ouro

### As 6 regras que você DEVE seguir:

1. **70% prática, 30% teoria** — assistir vídeo não te faz aprender. Fazer projeto te faz aprender.
2. **30-60 min/dia consistente** > 5h em maratona no fim de semana
3. **Ensinar valida** — grava um vídeo curto (YouTube ou pro seu grupo) sobre o que aprendeu na semana
4. **Cliente é o melhor curso** — cada projeto real te ensina 10x mais que qualquer curso pago
5. **Especialização > generalização** — não tenta saber tudo. Escolhe uma direção e vai fundo
6. **Comunidade acelera** — estar em comunidades ativas acelera aprendizado em 5x

## 🎁 Como a Logística te ajuda (não esquece disso)

Sua formação te deu **pensamento de processo** — e Automação Comercial é justamente processo com IA. As conexões:

| Conceito de Logística | Como aparece em Automação Comercial |
|---|---|
| Gestão de estoque | Gestão de leads no funil |
| SLA de entrega | SLA de resposta do bot |
| Roteirização | Fluxo do lead pelo funil |
| Otimização de rota | Otimização de conversão |
| Rastreio de pedido | Rastreio de lead ao longo do funil |
| Análise de gargalos | Análise de onde o lead trava |
| KPIs operacionais | Métricas do bot (conversão, score, etc) |

**Use esse vocabulário nas propostas comerciais.** Diferencia você de qualquer dev puro.

## 🥇 FASE 1 — Fundação (0-60 dias)

**Objetivo:** entregar o primeiro cliente com confiança. Não gaguejar em reunião.

### 1.1 — Python básico-intermediário (10-14 dias)

**Você já sabe fazer bot rodar. Agora entenda O QUE tá rodando.**

**O que priorizar aprender:**
- [ ] Funções (`def`, `return`, argumentos)
- [ ] Estruturas de dados (`list`, `dict`, `set`, `tuple`)
- [ ] `try/except` (tratamento de erro)
- [ ] List comprehension
- [ ] Classes básicas
- [ ] `import` e módulos
- [ ] Manipulação de arquivos (`open`, `json`, `csv`)

**Recursos GRÁTIS:**
- [ ] [Curso em Vídeo (Gustavo Guanabara) — Python 3](https://www.youtube.com/user/cursosemvideo/playlists?view=50&sort=dd&shelf_id=8) — módulo básico completo
- [ ] [Real Python](https://realpython.com/tutorials/all/) (inglês, mas Google Translate resolve)

**Livro recomendado (investimento R$ 90):**
- [ ] "Python Fluente" — Luciano Ramalho

---

### 1.2 — APIs REST (5-7 dias)

**Você vai usar em TODOS os projetos daqui pra frente.**

**Conceitos:**
- [ ] Métodos HTTP: GET, POST, PUT, DELETE
- [ ] Headers, body, response
- [ ] Autenticação (API Key, Bearer Token)
- [ ] JSON parsing
- [ ] Códigos de resposta (200, 400, 401, 404, 500)

**Recursos:**
- [ ] [Rocketseat: O que é API REST](https://www.youtube.com/results?search_query=rocketseat+api+rest)
- [ ] [Filipe Deschamps: Como funciona uma API](https://www.youtube.com/@FilipeDeschamps)
- [ ] [Postman Learning Center](https://learning.postman.com/) — ferramenta pra testar APIs

---

### 1.3 — Prompt Engineering Avançado (7-10 dias) ⭐ DIFERENCIAL

**Todo mundo usa IA. Poucos escrevem prompts BONS. Isso é seu diferencial.**

**O que praticar:**
- [ ] System prompt vs user prompt
- [ ] Chain of Thought (raciocínio passo a passo)
- [ ] Few-shot prompting (dar exemplos)
- [ ] Persona/character prompting
- [ ] Structured output (JSON mode)
- [ ] Guardrails (limites da IA)
- [ ] Temperature, top-p, max tokens

**Recursos GRÁTIS:**
- [ ] [Prompt Engineering Guide (dair-ai) — em português](https://www.promptingguide.ai/pt)
- [ ] [Anthropic Prompt Engineering Course](https://github.com/anthropics/prompt-eng-interactive-tutorial) — oficial, grátis
- [ ] [OpenAI Cookbook](https://cookbook.openai.com/)
- [ ] [Learn Prompting](https://learnprompting.org/)

## 🥉 FASE 3 — Diferenciação (120-180 dias)

**Objetivo:** você para de competir com "chatbot maker". Vira REFERÊNCIA.

### 3.1 — LangChain / LangGraph (15-20 dias)

**Isso te leva de "bot que conversa" pra "agente que age".**

**Diferença crucial:**
- **Bot:** responde perguntas
- **Agente:** executa tarefas (consulta CRM, envia email, marca reunião)

**Recursos:**
- [ ] [LangChain Academy (oficial, grátis)](https://academy.langchain.com/)
- [ ] [LangChain Docs](https://python.langchain.com/docs/introduction/)

### 3.2 — RAG (Retrieval Augmented Generation) (15 dias)

**Aqui você aprende a fazer IA que consulta base de conhecimento do cliente.**

**Casos de uso premium:**
- Bot que responde sobre a política interna da empresa
- Bot que consulta catálogo de produtos
- Bot que "leu" toda a documentação do cliente
- Assistente jurídico que responde com base em leis específicas

**Ticket típico com RAG:** R$ 5.000-15.000

**Recursos:**
- [ ] [DeepLearning.AI — LangChain: Chat with Your Data](https://learn.deeplearning.ai/courses/langchain-chat-with-your-data/)
- [ ] [Sam Witteveen — RAG videos](https://www.youtube.com/@samwitteveenai/videos)
- [ ] [Pinecone Learning Center](https://www.pinecone.io/learn/) — banco vetorial
